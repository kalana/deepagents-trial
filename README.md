# deepagents-trial

A small, hands-on learning project to try out [LangChain Deep Agents](https://docs.langchain.com/oss/python/deepagents/overview): an agent that turns a topic into a short, cited research brief.

> Status: work in progress. 
> Decision notes and documentation are in `docs/`folder.

## Setup
```bash
uv sync
cp .env.example .env   # then fill in keys
```
